# Project Cover Images (`public/images/projects/`)

Each project card in the portfolio loads its cover image from a stable filename in this directory (automatically synced with the root `Resorces/` directory during development and build).

## Filename Mapping

1. **`restaurant-inventory.png`** — AI-Powered Restaurant Inventory & Procurement Management System
2. **`academic-risk.png`** — AI-Based Academic Risk Prediction & Decision Support System
3. **`landsales.png`** — LandSalesDZ / LandConnect
4. **`medical-store.png`** — Online Medical Store Web Application
5. **`cctv-anomaly.png`** — AI-Based CCTV Anomaly & Human Safety Detection System
6. **`greenhouse-iot.png`** — IoT Greenhouse Automation System

## Replacement Instructions

- Replace any image in **`Resorces/`** or **`public/images/projects/`** using the **exact same filename and `.png` extension**.
- Recommended dimensions: **1200 × 675 px** (`16:9` aspect ratio).
- No code or data file changes are required.
- After replacing an image locally, commit and push the change to GitHub so GitHub Actions redeploys the site with the new image.
